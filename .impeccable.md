## Design Context

### Users
Marketing and brand professionals (social media managers, performance marketers, creative directors) managing paid and organic campaigns across platforms. Used in an office or home desk context, primarily on laptops (1366×768–1440×900) and widescreen monitors. High-frequency daily use — this is their operational command center, not a casual product.

### Brand Personality
Electric, precise, ambitious. Three words: **fast, dense, unimpressed**.

The product exudes quiet confidence — it is not trying to look impressive, it IS impressive. Think mission control, not marketing site.

### Aesthetic Direction
- **Theme**: Dark-first ("galaxy" aesthetic). Deep space backgrounds (`#020617`, `#0B1220`), electric blue-violet primary (`#5A48F9` light / `#7C6FFF` dark).
- **References**: Linear, Vercel dashboard, Raycast — density-forward, every pixel earns its place.
- **Anti-references**: Notion-style white space maximalism, SaaS landing pages with hero metrics and gradient text, any glassmorphism for its own sake.
- **Motion**: Purposeful only. Framer Motion for state transitions, 150–250ms, ease-out. No decorative bounce or sparkle.
- **Typography**: Inter (established, don't disturb). Semantic scale — tight `text-[11px]` labels, `text-sm` body, `text-base` emphasis. No fluid type in product UI.

### Design Principles
1. **Density over breathing room** — pack useful information in; whitespace is a bug not a feature in a professional tool.
2. **Relational sizing** — all spacing and min-heights scale with viewport via CSS variables and `clamp()`/`dvh`, never absolute pixels for layout floors.
3. **Interruptible motion** — CSS transitions for interactive state changes (hover, press), Framer Motion only for panel entrance/exit.
4. **Specificity in transitions** — always name exact properties (`background-color, color, scale`), never `transition: all`.
5. **Minimum 40×40px hit areas** — extend with pseudo-elements on small icons, never let adjacent targets overlap.
