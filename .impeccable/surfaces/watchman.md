# Watchman teammate workspace

Watchman uses Continuum's existing app shell, typography, Base UI controls, shared spacing tokens, borders, muted surfaces, and status pills. Teammate identity and current work are the main navigation. Setup offers Content, Performance, GTM, and Marketing lead responsibilities with editable plain-language first tasks.

The desktop layout places the team roster beside work and the Needs you queue. Narrow layouts retain the same order and accessible controls. Avoid inventing a separate visual system. Work rows and conversation timelines prioritize task title, actual state, blocker, and next human action. Model budgets are labeled as model budgets; a ready connection is distinct from an active teammate and from verified work completion.

Generated interaction is composed from known text, work, question, approval, report, and evidence leaves. UI SDK handles the supported action behavior; shared app buttons, fields, cards, safe Markdown, localization, keyboard focus, and form validation remain consistent. Material approval facts, exact operation/version identity, expiry, refusal and errors remain visible.

Pending setup remains available after partial provisioning. Empty, loading, paused, waiting, blocked, failed and partial states carry concrete recovery actions. Denied access clears cached private views. Transient network failures preserve drafts and offer retry with the same request identity.

Source/component checks are recorded in the implementation ledger. Browser, responsive visual, keyboard and trusted real-event acceptance remain unrun; this surface brief is not visual sign-off.
